Introduction to Memory System Techniques/Basic Life Support Algorithms

When you see or hear of someone performing what seems to be incredible feats of memory such as memorizing a roomful of peoples names or cards that have been played in a card game they are almost always using some form of memory system technique. Memory system techniques are not new and originated in ancient times (Lorayne and Lucas chapter 1).

Memory system techniques such as the ones coverd in this website are a hidden gem for remembering many things in our daily lives such as grocery lists, peoples names, phone numbers, speeches and many other useful information. Some have questioned why memory system techniques are not at least introduced in someway in our education process.

In addition to daily uses memory sytem techniques can help foster long term memory of important and complex information. One example of such information are the 2025 American Heart Association Guidelines for Cardiopulmonary Resuscitation and Emergency Cardiovascular Care Algorithms. Good recall of these algorithms can not only be helpful in passing ones basic life support certification but actually retaining the information long term in the event it is critically needed.

Intents of this Website

As alluded to by the website title there are really two intents of this website:

  • The first intent is an introduction to memory system techniques. More thorogh books and websites on memory system techniques are available but enough different aspects of several memory system techniques are covered to be a good starting point of one way of using memory system techniques.
  • The second intent is demonstrating how memory system techniques can be used to memorize more complex information in the form of Basic Life Support algorithms which now also include Foreign Body Airway Obstruction algorithms. Hopefully if used the process can help one retain the information in the event it is critically needed.

To try to meet these intents this website will start with a review of Memory System Techniques and use a pratice algorithm Fish Baits to demonstrate the concepts and memorize the algorithm. Then the same concepts will be used to memorize the components of the Basic Life Supportalgorithms, Basic Life Support and Foreign Body Airway Obstruction.
