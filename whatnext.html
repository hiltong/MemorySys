What Next?

Many of the basic concepts of memory system techniques have been covered in the previous pages. There are multiple options for further study and application including:

  • If memory system techniques do not seem to be something you are interested in I can undrstand if you abandon them as to be honest they initally seem weird. I remember when first introduced I had the simular feeling BUT the person who introduced them to me had an incredible memory and envy forced me to investigate them further for which I am thankful. I would recommend before abandoning memory system techniques at least read More Uses to see some of the ways they can be useful in daily life.
  • If you are mildly interested in memory system techniques I would recommend starting slow with the basic concepts of visual mnemonics and links which are usually very easy to grasp. I would hold off initally on learning visual numbers and letters as they are more complex. Also mind mapping and method of loci are not needed for many basic uses so I would delay learning these also. Spaced repetition is really just practicing which if for simple task a small amount never hurts. I would then use visual mnemonics and links for daily needs such as shopping lists and other uses noted under More Uses. This is what I personally did and it was not long belore I saw the benefits of memory system techniques and learned visual numbers, etc.
  • If you are very interested in memory system techniques after reviewing the basic concepts outlined on the previous pages spend time learning the basic concepts. Also read about memory system techniques from other sources which can from printed material found in books, internet searches and YouTube videos. By branching out you may find authors who present memory system techniques in a way that resonates with you better than this web site. Again many memory system techniques users use the basic concepts as a foundation but then add there own modifications to the basic concepts that work better for them.
  • If interested in memory system techniques and in Basic Life Support read the section on the subject and see one way of leaning the algorithms. It is of note "Visual Numbers" are neede for the basic life support algorithms.
