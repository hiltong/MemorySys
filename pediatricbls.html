  • Respiratory arrest images:

    • Respiratory arrest: A pair of deflated purple lungs in a crib.

      Respiratory resuscitation: You need to be able to mentally visualize 5 images lined up in a row which are lower case a,b,c,d alphabet learning blocks and an ox with nails sticking out of hide sitting and leaning back on the D block.

        • The a block is for "open airway"

          The b block is for "give breaths every ___"

          The c block is for "check pulse every 2 minutes"

          The d block is for "do CPR if ___"

          The ox with nails sticking out of hide is for "Give naloxone if possible opiod overdose"

        We need to learn what these blocks represent strongly for 2 reasons. First they will be used again in adult basic life support except to foster the pediatric flowchart they will be upper case ABCD to highlight being used in the adult flowchart. Second if we know what they stand for all we have to do is add modifiers to them with mental images to define them in more detail. We will attach modifiers to the letters.

        • The a is the same for both adult and pediatric basic life support and has no modifiers.

          The b block will have a mental image modifier added to indicate how frequent to give breaths which does differ between adult and pediatric basic life support.

          The c block modifier will have the same mental image modifier for both adult and pediatric basic life support for when to check pulse. It will be a cuckoo clock with Noah popping out saying cuckcoo (Noah if using the major system, a swan if using the shaper system, shoe if using the rhyming system). The cuckcoo clock will replace the straight vertical part of both the lower case and upper case versions of the letter c.

          The d block will have different mental image modifiers between adult and pediatric basic life support as to when to do CPR.

          The ox with nails sticking out of hide is the same for both adult and pediatric basic life support and has no modifiers.

          To help recall note that only the b and d blocks will have different mental image modifiers for adult and pediatric basic life support.

        ★ It is important to practice what the above blocks represent before you go further. You should be able to mentally visualize the images lined up in a row and as you mentally move down the line quickly say "Open airway" | "Give breaths every" | "Check pulse every 2 minutes" | "Do CPR if" | "Give naloxone if possible opiod overdose". If you can foster a good recall of these you will be much more likely to perform if ever needed in an emergency when things can be stressful.

      every 2-3 seconds (modifier for "give breaths every ___ seconds""): A stopwatch (seconds) with two start/stop buttons on top. The first button is replaced by Noah (seconds) sticking up and then second button is replaced by a lawn mower (3). The number 2 is Noah if using the major system, glue if using the shaper system, a tree if using the rhyming system. The number 3 is mow if using the major system, lips if using the shaper system, a tree if using the rhyming system.
