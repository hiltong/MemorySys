Basic Concepts/Fish BaitsAlgorithms

There are many uses for memory system techniques. Some are very simple like a shopping list and only the basic concepts of Visual Mnemonics and Links are needed. To cover most of the basic concepts a more complex memory challenge is needed. Because of their hierarchical structure algorithms are often more challenging to remember than a shopping list and can be used to demonstrate most of the basic concepts.

The basic concepts of memory system techniques that will be covered in this web site will be:

  • Mind Mapping
  • Visual Mnemonics
  • Links
  • Method of Loci
  • Spaced Repetition
