More Numbers

Using the Major System these are numbers 0-100 that I use as premade mental visual images. You can practice reviewing by clicking on the number (or image if showing) to see the corresponding image or number. Remember the images are what I personally use so use an image that works best for you.

Some memory experts are reported to have a list of a 1000 or more premade numbers. For longer numbers you encounter you can link premade numbers. By linking premade numbers together you can quickly and accurately remember a long digit number. You can also make up a number for the occasion. For example if you are faced with the number 1020 you could picture toes(10) being stuck up a nose(20) or you could use a word such as Tysons(1020) which to me is a mental image of a Tysons frozen dinner.
