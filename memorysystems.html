Overveiw Memory System Techniques

Memory system techniques can also be referred to as memory mnemonics which basically means techniques to aid information recall. There many forms of memory system techniques such as acrostic mnemonics as “Every Good Boy Does Fine” for musical notes or rhyming mnemonics such as "30 days hath September, April, June ...". In medicine there are many acronym mnemonics such as ABC (Airway,Breathing,Circulation) and CAB (Compressions, Airway,Breathing).

Several types of memory system techniques are covered in this website as listed below.

  • Mind Mapping (information is simplified and organized around a single central topic with radial branches of information)
  • Visual Mnemonics (information is attached to mental visual images)
  • Links Associations (mental visual images of information are associated with one another)
  • Method of Loci Associations (mental visual images of information are associated with mental images of known locations)
  • Spaced Repetition (information learned with memory sytem techniques still need pratice to reinforce long term recall but not near as much as with rote memorization)

You will not have to research far to find sometimes the termonolgy of memory system techniques sometimes confusing. In actual practice Mind Mapping and Spaced Repetition are more simplying/organizing information as well as praticing the learned information and not truly classic memory system techniques. Visual Mnemonics, Link Associations and Method of Loci Associations are all sometimes included under the term Visual Mnemonics. Method of Loci Associations are often called Memory Palaces. Naturally everyone who uses memory system techniques will have their own preferences but I find Visual Mnemonics and Link Associations the cornerstone memory system techniques I use. I will use Mind Mapping and/or Method of Loci Associations with more complex memory challenges. Of course some amount of Spaced Repetition depending of the situation is never wrong.

Ideally one would be familiar memory system techniques before accessing this website for which the previous referenced book would be an excellant start. For those not familar with memory system techniques you can still by working through this website get a condensed exposure to the basic concepts. We will start with a non-medical pratice algorithm about Fish Bait and work through the componemts of memory system techniques needed to memorize the algorithm. Then we will be prepared to apply memory system techniques to basic life support algorithms.

Other Considerations

The use of memory system techniques that I describe in this website are how I practice them which may not be exactly the same as you read of another author practicing memory system techniques. That is one of the strengths of memory system techniques, the basic concepts are the same but each individuals customization is what makes it work for anyone. When we get to mental visual images I will stress your initial personal menat visual images will usually be better for you than the images I may use as an example. When we get to numbers you will see how I simplied the major system when I was younger secondary to may difficulty with phonics which if I had started at my age now I probably would not do as I am more comfortable with phonics. The important point is to customize the memory system techniques to what works for you.

In the pages of this website the term "rote memorization" when used refers to the type of memorization we have all done since childhood such as learning the abc's or The Pledge of Allegiance. Rote memorization is still required some with memory systems, especially with numbers, but just not near as much. Also I always felt I had adequated rote memory but sometimes dreaded learning information by it reviewing over and over in my head, using flash cards,etc. Personally with the memory system techniques described in this website I do not dread the learning of new information and sometimes find it can even be enjoyable and sometimes depending on the ridiculous mental visual images I may use entertaining, hopefully this will be the same for you!
